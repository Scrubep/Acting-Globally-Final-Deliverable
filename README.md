# Acting Globally Website Redesigned  
### Description: HCDE Capstone project working with Acting Globally to improve clarity, accessibility, and overall user experience of the Acting Globally website with a focus on supporting discovery and engagement more effectively. (page screenshots at bottom)  
#### May 2026   

## Coding: Joey Choi & Kristine Cho with the help of AI  
## Design: Joey Choi, Kristine Cho, Cara Huynh, Katherine Kang  

  
- **React 19** — UI framework
- **React Router v7** — client-side routing
- **Tailwind CSS v4** — styling
- **Vite** — build tool & dev server


## Prerequisites:  
Node.js v18+  
Git  
  
## Steps:   
1. Clone repo
2. Install dependencies
> npm install
3. Start dev server
> npm run dev
4. Open on local host
